Code editor

Pick a language and write code

Each language starts with a Two Sum solution: find the two positions in a list whose values add up to a target. Change it or replace it. Your code for each language is kept while you switch tabs.

Ctrl or Cmd + Enter to run · Tab adds spaces, Esc then Tab leaves the editor

JavaScript runs right here. Python, C++ and Java need an interpreter or compiler, so Run shows the command to use on your computer.
